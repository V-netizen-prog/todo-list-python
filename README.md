1. Консольный To-Do List

Простое консольное приложение для управления списком задач, написанное на Python.

2. Описание

Это мой первый учебный проект, созданный для закрепления основ Python. 
Программа позволяет добавлять, просматривать и удалять задачи, 
с сохранением данных в текстовый файл между запусками.

3. Функционал

- Добавление новых задач
- Просмотр списка задач
- Удаление задач по номеру
- Автоматическое сохранение в файл
- Загрузка задач при запуске программы

4. Технологии

- Python 3
- Работа с файлами (чтение/запись)
- Функции и циклы
- Обработка пользовательского ввода

5. Как запустить

1. Убедитесь, что установлен Python 3
2. Скачайте файл `todo.py`
3. Запустите в терминале:
   ```bash
   python todo.py
